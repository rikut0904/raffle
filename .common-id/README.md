# Common ID integration package

This directory is generated by `common-id install`.

Use the Go SDK at `sdk/go/commonid` from the Common ID repository, or follow the integration guide:

- https://github.com/rikut0904/common-id/blob/main/docs/app-integration.md
- https://github.com/rikut0904/common-id/blob/main/docs/environment-contract.md

The application Backend must generate and store state/PKCE Pending values, exchange authorization codes, and issue its own HttpOnly session. Never put COMMON_ID_API_KEY, code_verifier, authorization codes, Firebase Admin credentials, or ID tokens in browser code or logs.
